# Alkaid Asset Generation Prompts

All 79 prompts for generating game assets. 64 image prompts (Gemini) + 15 audio prompts (ElevenLabs).

---

## How to Use

### Image Prompts (Gemini)

1. Go to [Gemini](https://gemini.google.com/)
2. Copy the **full prompt** below (it already includes the style prefix)
3. Ask Gemini to generate a 32x32 pixel art image
4. Download the result as PNG
5. Save to the file path listed with each prompt

### Audio Prompts (ElevenLabs)

1. Go to [ElevenLabs Sound Effects](https://elevenlabs.io/app/sound-effects)
2. Paste the **full prompt** below
3. Set the **duration** as specified
4. Click Generate
5. Download as MP3
6. Save to the file path listed with each prompt
